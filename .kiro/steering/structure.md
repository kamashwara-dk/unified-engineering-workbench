# Structure
`src/core` (pure C++), `src/server` (HTTP/jobs), `src/host` (Windows launcher), `src/ui` (frontend),
`tests/`, `data/` (+provenance), `results/` (raw CSV + labelled plots), `docs/`, `tools/` (C++ data generators),
`third_party/` (+VERSIONS.md). Use relative paths only. See docs/ARCHITECTURE.md.
